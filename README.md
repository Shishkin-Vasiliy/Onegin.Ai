# Onegin.Ai

> А.С. Пушкин так хорошо описал быт и нравы современной ему жизни в поэме "Евгений Онегин", что В. Г. Белинский назвал ее "энциклопедией русской жизни". Но в энциклопедии все должно быть отсортировано по алфавиту; гуманитарий Пушкин этого не знал. Помогите великому поэту сделать из поэмы настоящую энциклопедию, напишите эффективную по времени и памяти программу, которая читает стихотворные строчки из файла, сортирует их (игнорируя знаки препинания) и выводит в другой файл. В случае проблем с русским языком, используйте пьесы Шекспира. Пусть ему тоже мало не покажется.

## Задача

Прочитать текст произведения из текстового файла, отсортировать строки в нем двумя способами: сравнивая лексикографически строки идя слева направо и справа налево, вывести результат в файл `output.txt`. В конце также вывести оригинальный текст произведения.

## Архитектура программы

В заголовочном файле `header.h` содержатся все обьявления, #define-константы, прототипы функций.

Архитектура выглядит следующим образом:

```
.
├── include
│   └── header.h
├── src
│   ├── main.cpp
│   ├── Reading.cpp
│   └── Sorting.cpp    
```

`main.cpp` - управляющая программа, содержит также функцию распечатки
`Reading.cpp` содержит в себе функции открытия файла, чтения из него в специальный буфер, разделения буфера на строки и его очистку
`Sorting.cpp` включает в себя функцию сортировки (Qsort), компараторы и функцию обмена элементов значениями.

## Алгоритм решения

* Текст читается из файла с помощью функций `open()` и `read()` в один большой буфер.
* Буфер разделяется с помощью функции `SplitBuf()` на строки, затем адреса этих строк записываются в массив `index[]`. 
* Массив `index[]` передается функции `Qsort()` дважды для сортировки двумя способами: слева направо и справа налево. Алгоритм, используемый для сортировки - QuickSort с выбором серединного элемента в качестве опорного.
* После каждой сортировки новый текст выводится в файл `output.txt` с соответсвующим режимом сортировки.
* В конце работы функция `FreeBuf()` освобождает память, выделенную под буфер, а также заполняет эту память (в том числе и указатель на буфер) специальными значениями `POIZON_PTR` и `POIZON_CHAR`, определенными в `header.h`.

## Компиляция и запуск

Для компиляции программы в обычном режиме используется скрипт `build.sh`, для компиляции в режиме отладки с флагами Деда - `build_debug.sh`.
